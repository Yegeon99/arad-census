# data 폴더 안내

각 파일이 무엇이고 어느 회차 것인지 한 줄씩 적었습니다. 모든 파일은 집계 수치만
담고 있으며 캐릭터 식별 정보가 없습니다. 캐릭터별 원본은 `data/checkpoints/` 아래에
두고 커밋하지 않습니다.

## 회차 구분

| 회차 | 뜻 | 파일에 붙는 표시 |
| --- | --- | --- |
| 1차 | 시드 36개로 모은 첫 조사. 리포트 화면이 쓰는 기준 | `census_2026-08` |
| 2차 | 시드 1,000개로 다시 모은 조사. 1차를 덮지 않고 나란히 보관 | `census_2026-08-r2`, `_r2` |
| 검증 | 명성 점수로 훑어 두 회차를 견주는 잣대 | `fame_probe`, `verification` |

## 집계 결과

| 파일 | 회차 | 내용 |
| --- | --- | --- |
| `census_2026-08.json` | 1차 | 표본 31,523명. 직업, 성장 단계, 서버, 교차표, 활성도, 인사이트 |
| `census_2026-08-r2.json` | 2차 | 표본 1,301,990명. 같은 기준으로 집계. 활성도는 다시 재지 않음 |
| `bias_notes.md` | 공통 | 편향과 한계를 항목별로 정리한 노트 |

## 수치를 다시 확인하려면

```bash
python scripts/verify_findings.py
```

`docs/findings.md`와 `README.md`가 인용하는 수치를 위 파일들에서 다시 계산해
대조합니다. 하나라도 어긋나면 실패로 끝납니다.
